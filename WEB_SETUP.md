# LIPP VPN Web Cabinet

Вся веб-часть лежит в этой папке `сайт`.

Сайт работает отдельно от Telegram-бота, но использует корневые файлы проекта:

- `../main.py` - общая логика VPN, YooKassa, x-ui и базы;
- `../.env` - настройки;
- `../vpn_service.db` - общая база пользователей, платежей и синхронизации.

## Запуск

Из корня проекта:

```powershell
pip install -r requirements.txt
cd сайт
python -m uvicorn web_app:app --host 127.0.0.1 --port 8000 --reload
```

После запуска откройте:

```text
http://127.0.0.1:8000
```

Альтернативно из корня проекта можно запускать так:

```powershell
python -m uvicorn сайт.web_app:app --host 127.0.0.1 --port 8000 --reload
```

## Что уже есть

- регистрация и вход по email/паролю;
- личный кабинет с логотипом LIPP VPN;
- выдача VLESS-ключа и ссылки подписки после оплаты;
- создание платежа YooKassa на сайте;
- ручная проверка платежа после возврата из YooKassa;
- обновление ключа для активной подписки;
- история оплат;
- ссылка на поддержку;
- синхронизация веб-кабинета с Telegram аккаунтом через одноразовый код.

## Переменные для сайта

Основные переменные берутся из корневого `.env`: `DB_PATH`, `YOOKASSA_*`, `PANEL_*`, `VPN_SERVER_HOST`, `REALITY_*`.

Дополнительно можно указать:

```env
WEB_PUBLIC_URL=https://your-domain.example
WEB_COOKIE_SECURE=true
WEB_SESSION_DAYS=30
WEB_USER_ID_BASE=900000000000
```

`WEB_PUBLIC_URL` нужен на боевом домене, чтобы YooKassa возвращала пользователя обратно на сайт.

## Синхронизация с Telegram

После обновления кода перезапустите и сайт, и Telegram-бота.

Пользовательский сценарий:

1. Войти или зарегистрироваться на сайте.
2. В кабинете нажать `Получить код` в блоке `Синхронизация с ботом`.
3. Отправить боту команду вида:

```text
/start web_ABC123
```

4. Вернуться на сайт и нажать `Обновить статус`.

После привязки сайт будет показывать подписку, ключ и платежи по Telegram `user_id`.
